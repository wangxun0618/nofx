# 2026-09-18

## 前端国际化（web/）—— 恢复语言切换 + 全量中文化

**背景**：项目曾在前端内置三语（en/zh/id）切换，后被提交 `7b8f2f00` 主动移除并锁死英文
（`LanguageContext` 硬编码 `'en'`，每次启动还用 `localStorage.setItem('language','en')`
覆盖用户选择；`HeaderBar` 里留下两处 `// Language switcher removed` 注释）。
但 `translations.ts` 里 en/zh 各 901 键、中文覆盖质量良好，切换器组件也还在，只是无人引用。

**用户决策**：中/英双语（移除印尼语）· 默认中文 · 全量中文化 · 仅做翻译不动布局。

**改动要点**
- `LanguageContext.tsx`：`Language` 收敛为 `'en' | 'zh'`；恢复 localStorage 持久化、
  `setLanguage`、`<html lang>` 同步；默认中文；新增 `setActiveLanguage()` 供非组件模块同步。
- 翻译字典分三层，`t()` 按序回退：`translations.ts`（旧表）→ `ui-strings.ts`（合并入口）
  → `pairs/*.ts`（按域拆分：faq / strategy / wallet / console / metrics / landing / lib）。
  新增 `translation-pair.ts` 定义 `PairMap`（扁平点号键，en/zh 均必填）。
- 非组件模块（`lib/`、`model-constants.ts`、`clipboard.ts` 等）用 `tg(key, params?)`
  读取「环境语言」，避免在普通函数里调 `useLanguage()` 造成 Hook 违规。
- 清掉两类历史遗留：**硬编码英文**（约 130 处）与**假中文三元分支**
  （`language === 'zh' ? 'English' : 'English'`，约 90 处）。
- 删除印尼语块 + 所有 `'id'` 分支；移除残留死字段（如 `FunnelLayer.zh`）。
- 切换入口覆盖：HeaderBar（桌面 + 移动菜单）、Header、LoginPage、RegisterPage、
  SetupPage（首次初始化界面）、RegistrationDisabled、WhitelistFullPage。

**验证**
- `npx tsc --noEmit` 干净；`npx vitest run` 167 passed（13 个文件）；
  `npx vite build` 成功（2928 模块）。
- 运行时校验：930 个被引用的键在中英文下全部可解析；仅 `strategy.tradeFi`
  的 zh 与 en 相同（TradeFi 为行业合成词，合理保留）。
- 新增 `src/components/landing/landingI18n.test.tsx` 集成测试，真实挂载落地页区块，
  断言默认中文渲染、持久化英文渲染、点击切换器双向实时切换文案。
- `src/test/setup.ts` 补了 `IntersectionObserver` 垫片（jsdom 缺失，framer-motion
  `whileInView` 组件此前无法在测试中挂载）。

**刻意保留英文**：品牌名（NOFX / Hyperliquid / Claw402 / Binance / OKX / MetaMask…）、
模型名（Claude Fable 5 / GPT-6 Astra…）、交易所模板名（Binance Futures…）、
LaTeX 公式、LLM 提示词 `promptEn`、API 动作标识（`HyperliquidTransaction:ApproveAgent`）、
标准术语（Pre-IPO、VaR、TradeFi）。

**已知遗留（未处理，非用户可见）**：`StrategyStudioPage.tsx` 中 `signalBiasInfo` 的
`hint` 字段（`Long bias` / `Short bias` / `Neutral bias`）只声明未被读取，是死数据
（已 grep 确认无 `.hint` 访问点）；`constants/branding.ts` 的 `BRAND_INFO` 同样只有导出无引用。

**注意**：macOS 的 BSD grep 不支持 `\|` 交替，必须用 `grep -E` 或 Grep 工具，
否则会静默返回空结果并导致误判（本次踩坑两次）。
