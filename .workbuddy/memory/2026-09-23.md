### 四、环境坑：vite dev server 在本沙箱跑不起来（非项目缺陷）

`npm run dev` 会**崩溃退出**，根因是沙箱 `node-safe-delete-shim` 的批量删除保护：
vite 懒发现依赖后重新优化要删 `node_modules/.vite/deps_temp_*`（58 → 79 个文件 > 阈值 50）。
第一次 `rm -rf node_modules/.vite` 后能起来，但**访问页面触发二次优化时再崩**。

同样根因也导致 `vite build` 默认输出（`prepareOutDir` 清空 `web/dist`）失败。

**可行绕法**（已验证）：
```bash
./node_modules/.bin/vite build --outDir /tmp/nofx-web-build --emptyOutDir   # 1m53s, EXIT=0
node /tmp/nofx-web-serve.js     # 极简静态服务 + /api 代理到 8080，监听 3000
```
`/tmp/nofx-web-serve.js` 是我写的临时脚本（SPA fallback + 路径穿越防护），仅沙箱环境用。
