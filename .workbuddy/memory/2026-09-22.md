### i18n 改造方法（可复用）
- 结构：`translations.ts`（legacy 表，裸标识符 `key: 'value'`）+ `ui-strings.ts`（`uiStringPairs` 内联 + `build()` 合并 `pairs/*.ts`，PairMap 形如 `'ns.key': { en, zh }`）
- 审计脚本要点：bundle 出 en/zh 全量 key → 扫描 `src/**/*.{ts,tsx}`（**必须排除 `src/i18n/` 自身**，否则每个 key 都会因定义行而假性「被引用」）→ 匹配 `t('k')` / `tg('k')` 以及**所有等于已有 key 的字符串字面量**（覆盖 `titleKey: 'hlw.x'` 这类间接引用）
- 只有 2 处动态拼接 key：`loginRequired.${key}`、`comparisonChart.${period.key}`
- 删除时按「`'key': {` → 括号平衡到闭合」精确剔除；删除后务必复查 en/zh key 对称
- 本次结果：translations 901→879、uiStrings 780→625，en/zh 完全对称
- 删除的两个无引用死组件：`BeginnerGuideCards.tsx`、`OnboardingModeSelector.tsx`
- 注意：`tr(...)` 在 `LoginRequiredOverlay.tsx` / `OperationGuide` 一类文件里是**本地包装函数**，不是 i18n 调用，审计时会误报 missing
